# 📚 영어 동화책 읽어주기

브라우저 내장 음성(Web Speech API)으로 영어 동화를 읽어 주는 웹앱입니다. **비용 0원**, 인터넷 API 없음.

## 수록 동화 (모두 공개영역)
Goldilocks and the Three Bears · The Three Little Pigs · Little Red Riding Hood · The Ugly Duckling · Cinderella · The Tortoise and the Hare

## 사용법
1. `index.html`과 `stories.js`를 같은 폴더에 두고 엽니다. (웹서버/GitHub Pages 등에 올리면 아이폰에서 가장 편해요)
2. **아이폰 사파리**에서 주소를 열고 → 공유 버튼(□↑) → **홈 화면에 추가** 하면 앱처럼 쓸 수 있어요.
3. 동화 카드를 누르고 → 아래 **▶︎ 읽기** 버튼을 누르세요. 읽는 문단이 노란색으로 표시됩니다.
4. ⏸ 잠깐 / ⏹ 멈춤, 🐢~🐇 슬라이더로 속도(0.7~1.2배), 목록에서 목소리(en-US/en-GB) 선택.
5. 문단을 직접 누르면 그 문단부터 읽어요.

## 주의
- 사파리는 **첫 재생을 반드시 사용자가 버튼을 탭해야** 소리가 나요 (자동 재생 불가).
- 아이폰 **무음 모드(옆 스위치)** 가 켜져 있으면 소리가 안 날 수 있어요.
- 더 자연스러운 목소리: 설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 영어에서 "향상된/고품질" 음성 다운로드.
- 사파리에서 일시정지 후 재개가 불안정하면 읽던 문단을 직접 탭하면 그 문단부터 다시 읽어요.
